# Local agent tools
Run from the repository root:
```bash
bash tools/install-local-agents.sh
```
This installs the Browser Use MIT Python package and the Open Interpreter Apache-2.0 standalone CLI. These are local tools and must be run on a machine you control. Do not expose unrestricted terminal execution to the public internet. Browser Use can connect to a local Chromium browser; hosted browser/model services may charge separately.
